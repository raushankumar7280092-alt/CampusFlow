I built CampusFlow — a Smart University Management System designed to make everyday campus information easier to find.

Announcements, event details, classroom schedules, and assignment deadlines can be spread across different channels. CampusFlow brings those student essentials together in one dashboard, with an admin view for managing key information.

Students can browse announcements and events, check their timetable and assignments, and register for campus events. Registration is stored in MongoDB, with duplicate-registration and event-capacity validation. Administrators can create and update events, publish announcements, and review registrations and dashboard statistics.

The project uses HTML, CSS, and vanilla JavaScript on the frontend, with Node.js, Express.js, MongoDB, and Mongoose powering the backend and REST APIs.

Building CampusFlow gave me practical experience connecting a responsive interface to persistent data, designing and exercising REST endpoints, and handling real workflow cases such as duplicate and full-capacity registrations. It was developed for the Prompt2Pixel Round 3 competition.
