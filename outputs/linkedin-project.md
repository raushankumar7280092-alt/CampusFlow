# CampusFlow — Smart University Management System

**Short description**

A full-stack smart campus platform that centralizes announcements, events, event registration, timetables, assignments, and administrative management.

**Technology**

HTML · CSS · JavaScript · Node.js · Express.js · MongoDB · Mongoose · REST API

**Key features**

- Student dashboard
- Announcements and upcoming events
- Event details and registration
- Duplicate registration protection and capacity validation
- Timetable and assignment tracking
- Admin dashboard for managing campus content and reviewing registrations
- MongoDB persistence through REST APIs
